## 1 + 2 — Merge + range 1→47
- **`index.html`**: removed the standalone `#path-preview` box (and its own 1–12 slider/row).
  The Path Preview `.gadget-switch` (`#path-preview-on`) now lives **inside** `#banana-gadget`,
  below the result. The gadget range is now `min=1 max=47` (was 1–12).
- **`game-screen.js`**:
  - `setBananaGadget(n)` clamps **1–47** (was 1–12); when the preview is on it also re-renders
    the board so the yellow highlight tracks the new distance.
  - `togglePathPreview(on)` now syncs `#path-preview-on.checked` (so it can be driven
    programmatically) and dropped the dead `#path-preview-row` show/hide.
  - **Deleted** `setPathPreview` and `updatePathPreview` (+ its call site). The path preview no
    longer has its own amount — `_stepHiN` is gone.
- **`board.js`**: the PATH PREVIEW (yellow) set now uses `window._bananaGadgetN` (clamp 1–47)
  instead of `_stepHiN`. The BANANA REACH (green) set clamp also bumped 12→47. So both overlays
  share the single Banana Gadget distance.

## 3 — Arm a rune → path preview off
- **`game-items.js`** `armRollCard(value)`: after emitting `arm_roll_card`, if the yellow Path
  Preview is on it calls `togglePathPreview(false)` (the only client arm chokepoint; the rune
  chip click at game-screen.js routes through here). The cyan armed-roll path takes over.

- **`game-socket.js _renderRevealContent`**: desert tile `<span class="reveal-tile-icon">🌵</span>`
