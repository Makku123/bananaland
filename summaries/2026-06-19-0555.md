# Session 2026-06-19 0555 — Crossing the Super Banana (while affording) triggers the card auction

Request: when a player CAN AFFORD the Super Banana, crossing (passing over) the tile should trigger the guaranteed-roll card auction. Previously crossing did nothing (you had to LAND to win/auction).

Clarified with the owner: crossing does NOT reveal the SB tile (stays fog-hidden — only landing exposes it). The card auction behaves exactly like the existing can't-afford LANDING auction — the crosser is the auction "lander": privately sees the card during the auction; if the crosser wins it's CONCEALED, if another player wins it's a PUBLIC revealed card.

## Implementation (backend/gameLogic.js only)
- New method `_resolveSuperBananaCross(player, oldPos)`: bails if ghost/bankrupt, `state !== "playing"`, or `this.auction/this.poker/this.superBananaWin` set; walks the strictly-crossed tiles (`oldPos+1 … newPos-1`, mod boardSize — excludes the landing tile); if it finds an unowned `superBanana` tile and `player.money >= prop.price`, calls `this._createCardAuctionForLander(player.id, this._randomRollCard())`. **No tile reveal** (fog preserved). Defined next to `_createCardAuctionForLander`.
- Wired in after `_processLanding(cur)` at ALL FOUR move sites: `rollDice`, `useRollCard` (normal), `useRollCard` (cancel-HIT 2d6 branch), `debugMove`. Placed BEFORE each site's `if (!this.auction && !this.poker) scheduleAutoEnd`, so a cross-opened auction suppresses the turn auto-end.

## Matrix (new)
- LAND + afford → WIN (unchanged); LAND + can't-afford → card auction + SB revealed (unchanged).
- **CROSS + afford → card auction, SB tile stays hidden (NEW).**
- CROSS + can't-afford → nothing; ghost/bankrupt → nothing (unchanged).
- Landing takes priority: if the landing tile starts poker / a farm auction / an SB win, the cross-helper bails (no double interaction / no clobber — guards on `this.auction/poker/superBananaWin`).

Reuses existing tested machinery: `_createCardAuctionForLander` (positionless `pos=-1`, self-guards on `this.auction`, handles 0/1/2+ bidders + 2v2/3v3 team flow), `_grantAuctionCard` (concealed-if-lander / revealed-if-other), getState cardValue lander-only redaction.
