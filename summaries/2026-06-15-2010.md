# Run summary — 2026-06-15 20:10 PT

Refinement to the Cancel Items ability: in **2v2 only**, each player gets a
**single** charge instead of two, but a cancel that **actually lands** (the
target uses a special item that gets nullified) **refunds the charge**. A wasted
cancel (target uses no special item that turn) is gone for good. Free-for-all is
unchanged (2 charges, never refunded).

## Backend (`gameLogic.js`)

- **Per-mode starting charges**, set in `completeReveal` (where mode is final):
  `cancelItems = this._isTeams() ? 1 : 2`. Also re-set in `returnToLobby`;
  `addPlayer` keeps a default.
- **Caster tracking for the refund:** queued cancels now record who cast them.
  `useCancelItems` sets `target.cancelQueuedBy = caster.id`; `endTurn` promotes
  `cancelQueuedBy → cancelActiveBy` alongside the existing queued→active
  promotion, and clears the just-ended player's `cancelActiveBy`.
- **Refund-on-success:** new `_refundCancelIfLanded(cur)` (gated to 2v2) returns
  the caster's charge, capped at `_cancelChargeMax()` (1 in 2v2), and consumes
  `cancelActiveBy` so it can't double-refund. Called from all three interception
  points (`rollDice` Turtle/Rabbit, `useMagicDice` Roll One, `useCard` Vine
  Swing) at the moment the item is nullified.
- `getState` now also strips the new `cancelQueuedBy` / `cancelActiveBy`
  (server-only).

No server or frontend changes were needed: the cancel handler is unchanged, and
the button label is data-driven off the private `cancelItems` count, so 2v2 now
shows "(1 left)" and snaps back to "(1 left)" when a cancel lands.

## Tests (`backend/test_game.js`, section 68c)

- Updated the 2v2 block: starts with **1** charge; rejected/teammate casts spend
  nothing; a successful cast drops it to 0 and records `cancelQueuedBy`.
- New: **2v2 refund** — a landed Turtle Dice cancel returns the caster to 1
  charge, clears `cancelActiveBy`, capped at 1.
- New: **2v2 no-refund** — target rolling normally (no item) leaves the caster
  at 0.
- New: **free-for-all no-refund** — a landed cancel keeps the charge spent (2→1).
- **Full suite: 820 passed, 0 failed** (was 805).
