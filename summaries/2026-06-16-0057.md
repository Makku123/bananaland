# Run summary — 2026-06-16 00:57 PT

Three follow-up tweaks to the 2v2 farm auction, all backed by tests, a live
frontend render check, and a two-reviewer adversarial pass.

## 1. Send Bananas frozen during auctions

- `tradeBananas()` now returns false whenever a farm auction (`this.auction`) OR
  an item auction (`this.itemAuction`) is live — no funneling money to the bidder
  mid-auction. (`gameLogic.js`)
- Frontend: `#btn-send-bananas` is disabled (with a "Can't send bananas during an
  auction" tooltip) and its panel is force-closed while `gs.auction ||
  gs.itemAuction` is live, so the lockout is visible, not a silent no-op.
  (`game-screen.js`)

## 2. Lander "Buy Now" → teammate gets a say (2v2)

The 2v2 lander Buy Now is no longer an instant win. It's priced at **richest
opponent + 1** (the teammate's bank is never counted) and now *pitches* that
lock-out price, then runs the normal post-pitch flow:

- No opponent can afford it → it goes to A2's final say: **Accept** (A2 buys at
  that price) or **Reject** (A1 buys at that price).
- If A2 also can't afford it → A1 buys instantly.
- `auctionBuyNow()` branches on `a.teamFlow` (sets the lander's pitch + calls
  `_2v2AfterPitch`); the classic free-for-all Buy Now is untouched (still instant).
- Button relabelled **"🏷️ Highest opponent score +1 (X🍌)"** in 2v2 (classic
  still "💰 Buy Now"), per the user's request.

## 3. One-opponent contested silent bid

When exactly **one** opponent can afford P (the other is excluded) **and** the
teammate can afford P, the teammate's "Accept" no longer just buys at P — it
opens a silent bid:

- Flow: pitch → that opponent Accepts → A2 **Contest** → silent bid (opponent vs
  A2), each secretly adds a **top-up on top of P**, highest total wins and pays
  P + top-up. A **tie sends the farm to the lander (A1) at P**.
- New `_2v2StartContestedSilentBid()`; `_resolveSilentBid` tie branch now keys
  off `a.silentTieToLander` (contested → lander at P; broke-lander → teammate, as
  before). The two-opponent raise/oppFinal path is unchanged.
- Frontend: teammate one-opponent button relabelled **"✅ Contest"** with a
  "Contest it in a silent bid" prompt; the silent-bid keypad/cap reused as-is.
