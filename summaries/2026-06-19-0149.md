## Guaranteed Rolls (new)
- Each player starts with **6 cards, each a random 1–6** (`player.rollCards`,
  duplicates allowed). The old "special items" box is now **"Guaranteed Rolls"**
  (`#guaranteed-rolls-list`), one clickable `🎲 N` button per card.
- **`useRollCard(socketId, index)`** — optional substitute for your dice roll on
  your turn: move exactly N, fire GROW N if revealed, consume the card, one per
  turn (`!diceRolled` gate). Socket event `use_roll_card { gameId, index }`.
- **Gain cards by LANDING on the Super Banana when you can't afford it** → +1
  random card (replaces the old +20 bonus, which is gone). A ghost gets nothing.
- getState ships the viewer's own `rollCards` array + everyone's `rollCardCount`
  (others' card numbers are fog-redacted).
