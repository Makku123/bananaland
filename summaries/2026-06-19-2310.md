# Session 2026-06-19 2310 — Bugfix: rich SB cross only triggers when the SB is REVEALED

Bug report: the Super Banana card auction triggered when a **rich crosser crossed the Super Banana
while it was still UNREVEALED**. It shouldn't.

## Root cause
`_resolveSuperBananaCross` gated only the **broke** (+50) branch on `player.revealedTiles.has(sbPos)`;
the **can-afford** branch fired the card auction regardless of whether the SB was revealed. So a rich
player crossing a still-fog-hidden Super Banana opened the auction.

## Fix (gameLogic.js `_resolveSuperBananaCross`)
Added a single reveal gate right after locating the crossed SB:
`if (!player.revealedTiles.has(sbPos)) return false;`
Now crossing a **hidden** Super Banana does **nothing** — for rich and broke alike — and still never
reveals it. Only a **revealed** SB cross triggers: rich → card auction (deferred landing), broke →
+50. (Landing is unaffected; a landing still reveals + resolves the SB normally.) Collapsed the old
two-branch reveal handling into the one gate; updated the docstring.
