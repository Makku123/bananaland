## 2. Player-CHOSEN card discards for teleport + missed cancel
Previously both flows discarded 2 cards at **random** (`_removeRandomRunes`). Now the player chooses.

### Backend (`backend/gameLogic.js`, `backend/server.js`)
- New `_removeChosenRunes(player, indices)` — dedups, range-checks, splices **descending**, returns count.
- `teleportToFarm(socketId, position, discardIndices)` — uses the chosen 2 indices; **falls back to random** on any malformed/missing/duplicate/out-of-range input so the cost is always paid. Discard stays before the cancel-HIT branch (cost paid on success AND cancel-HIT).
- Missed cancel (`_resolveCancelOnRoll(cur,false)`): when the caster holds **>2** cards, the loss is **DEFERRED** — sets owner-only `pendingCancelDiscard` (no immediate removal), `lastCancelResult.needsPick`. The debt **accumulates** (`+= 2`) so two simultaneous-target misses both charge. Hand ≤2 → auto-random (legacy toast).
- New `resolveCancelMissDiscard(socketId, indices)` — `need = min(pending, hand)`, removes chosen, clears debt, reconciles armed roll. Caster is **gated** (rollDice/useRollCard/teleportToFarm/useCancelItems/armRollCard) while `pendingCancelDiscard > 0`.
- `pendingCancelDiscard` player field: init 0 in addPlayer; reset in completeReveal/_resetToLobby; cleared in makeGhost; **owner-only** in getState (secret from the target).
- Sockets: `teleport_to_farm` forwards `discardIndices`; new `cancel_discard_pick` (handler **always** re-emits so a rejected/stale pick re-syncs the caster — anti soft-lock).

### Frontend (`game-items.js`, `game-screen.js`, `styles.css`)
- Shared `openCardDiscardPicker(opts)` modal — renders the hand as tappable chips, caps selection at `count`, confirm gated to exactly `count`, returns chosen indices. Dismissible (teleport) vs non-dismissible (cancel-miss). Tags `dataset.mode` / `dataset.discardCount`.
- Teleport: `emitTeleportToFarm` opens the picker (count 2) then emits `{position, discardIndices}`; board click site unchanged.
- Cancel-miss: `showGame` auto-pops the non-dismissible picker when `me.pendingCancelDiscard > 0` (fires during the opponent's turn, non-blocking); **re-opens if the owed count changes**. `_cancelDiscardResolving` guard is cleared on **every** `game_update` (game-socket.js) so it can't latch and soft-lock the caster.

### Design decision (user)
Cancel-miss timing = **immediate popup at the miss** (during the opponent's turn), kept secret from the target.
