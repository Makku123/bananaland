## Confirmed bugs — fixed (+ regression tests)
1. 🔴 **HIGH — endTurn crash (TypeError → turn stuck).** The bomb-lifecycle loop
   in endTurn walked `this.bombs` by index while `_detonateBombSide` →
   `_bombEliminate` rebuilt the array (`this.bombs = this.bombs.filter(...)`),
   so when a blast eliminated a victim whose own live bomb sat at a lower index,
   a later iteration read `undefined.placedBy` and threw — endTurn never
   advanced. Reachable after a player **leaves** (desyncs the fuse cadence). This
   was my side-blast redesign's regression. **Fix:** iterate a snapshot of the
   placer's bombs and remove the detonating bomb by identity (crash-proof).
   Test 97a.
2. 🔴 **HIGH — getState.currentPlayer leaked private state to all opponents.** It
   was the RAW `getCurrentPlayer()` object, broadcast to every socket — leaking
   `clientId` (a reconnect-hijack token), an opponent's armed item, cancel state,
   and **every player's `revealedTiles`** (a fog back-channel that could expose a
   relocated hidden Super Banana's position). Pre-existing. **Fix:** build the
   per-player redaction once and set `currentPlayer` to the redacted `players[]`
   entry; stop shipping non-viewers' `revealedTiles` entirely (frontend only ever
   reads its own `me.revealedTiles`). Test 97b. Verified the frontend reads none
   of the stripped fields.
