## Random first-turn start pick

- `gameLogic.pickStartTileRandom(socketId)`: same guards as pickStartTile
  (playing / current player / startPickPending / no auction-poker-SB), builds
  the occupied set = positions of other players who are on the board (not self,
  not bankrupt, not startPickPending), picks a uniformly random tile NOT in that
  set, and resolves it through `pickStartTile` (which re-validates). Guarantees
  the user's rule: the 2nd/3rd/4th picks can never land on another player.
- `server.js` `pick_start_tile_random` handler mirrors `pick_start_tile`,
  including the 30s super-banana AFK fallback (a random pick can land on the SB).
- Frontend: `#btn-random-start` in the dice-box (next to the Roll button, which
  is disabled during start-pick), shown only when `isMyTurn && needsStartPick`;
  `pickRandomStart()` emits `pick_start_tile_random`. Styled blue.

## Random Super Banana relocate

- `gameLogic.randomSuperBananaSwap(socketId)`: guarded to the pending picker
  (`superBananaPending.playerId`, awaitingPick), delegates to the existing
  `forceSuperBananaSwap()` (random unrevealed-tile selection + complete).
- `server.js` `force_super_banana_swap` handler.
- Frontend: `#btn-random-superbanana` lives inside the `#super-banana-notification`
  banner with `pointer-events: auto` (the banner itself is `pointer-events:none`),
  shown only to the picker while a relocate pick is pending; `pickRandomSuperBanana()`
  emits `force_super_banana_swap`. Styled gold.
