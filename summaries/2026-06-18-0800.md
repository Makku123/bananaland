## Decisions & changes

1. **Broke-lander free farm (team mode)** → **keep as-is** (any opponent, incl. a
   0-banana one, can grab the free farm). No code change.

2. **0-banana item auction** → **team now matches classic.** In
   `_beginItemTeamPitch`, if NO opponent or teammate can pay even 1🍌, a non-ghost
   starter **keeps the item for free** (a ghost starter cancels) — instead of
   gifting a free item to a 0-banana opponent. Replaced the old solvent-starter-only
   guard with this universal one (also still covers the earlier deadlock fix).

3. **Pineapple bombs → single-tile TRAPS** (the big one):
   - Landing on a live trap eliminates **only that lander** — **no blast radius**
     (`_checkBombDetonation` rewritten; `explosion.tiles = [position]`). Placer and
     a placer's teammate still **defuse** on landing.
   - **No timer detonation**: when an armed trap's fuse runs out it is **removed
     harmlessly** in `endTurn` (never explodes). `_explodeExpiredBombs` → renamed
     `_removeExpiredBombs`, a silent safety sweep.
   - Killing a victim still transfers their estate, **defuses bombs they placed**,
     and refunds a cancel they were the target of.
   - Deleted the now-dead blast machinery: `_bombBlastTiles`, `_isCornerTile`,
     `_sideTiles`, and the dead `cur.bankrupt/finished` guards after each
     `_removeExpiredBombs()` call. Rewrote the bomb tests (45c, 69, 69b, 93b) for
     the trap model; updated the tutorial + rules.md + in-code comments.

4. **Dead `superBananaPending` / `superBananaHint` scaffolding** → **removed.**
   Stripped the always-null declarations, the getState serialization
   (`superBananaPending` object + `superBananaHintPos`), ~15 backend guard terms,
   the leave-game/rebind/reset handling, and the relocate hint-nulls; dropped the
   obsolete pending-pick tests. 0 residual references.
