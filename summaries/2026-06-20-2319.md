## Before

- `🐒 Your Monkey` (half) | `⚙️ Game Settings` (half: Players `#create-max`, Starting Bananas

  Starting Bananas, then the `.options-numbers--middle` grid (Super Banana / Farm Bid Timer), then
  the `.options-toggles` grid (Rune Duel / Public Lobby).
- Made `🐒 Your Monkey` full-width (`grid-column: 1 / -1`) so it isn't orphaned in the 2-col grid.
- `🎮 Game Mode` unchanged. **Every element ID preserved** (incl. the hidden `#create-mode` select
  and `#bananas-display`), so `createGame()` / `toggleModeSettings()` / `auth.js` wiring is intact.

Result: 3 stacked full-width sections — Your Monkey → Game Mode → Game Settings & Options.
