# Session 2026-06-20 2355 — Fix the "Reveal All Tiles" toggle (DEBUG-only)

User: "make the reveal all tiles toggle work. it currently does not work."

## Why it was broken
`toggleRevealAll()` only flipped a CLIENT flag (`revealAll`) and re-rendered. But since
2026-06-17 fog of war is enforced SERVER-SIDE: `getState(viewerId)` redacts unrevealed tiles to
`{id, type:"hidden"}` (and properties to `{hidden:true}`) BEFORE sending. So the client never had
the hidden tiles' data — the flag had nothing to reveal. A client-only fix is impossible; the
server must send the hidden tiles to whoever opts in.

## Scope decision (asked the user)
Making it work is a deliberate fog bypass (reveals the hidden Super Banana), and the toggle lives
in the always-visible Toggles panel — player-facing in real games. User chose **"Debug builds
only"**: fully reveal, but gated to non-production and hidden from the toggle list in production.

## Implementation
**Backend**
- `gameLogic.js` addPlayer: new per-player view flag **`revealAllView: false`** (pure view flag —
  never touches `revealedTiles` or game logic).
- `gameLogic.js` getState: `_fog = state==="playing" && !(viewer && viewer.revealAllView)`. A viewer
  with the flag gets the fully UNREDACTED board (also lifts the diceMatch / shuffle fog filters,
  since they key off `_fog`). Per-viewer — nobody else is affected.
- `server.js`: new socket **`set_reveal_all {gameId, on}`**, **gated by `DEBUG_TOOLS`**
  (`NODE_ENV !== "production"`) so production clients can never enable it. Sets the player's flag and
  re-emits THAT socket's `game_update` so the (un)redacted board arrives immediately. Mirrors the
  existing `toggle_no_timer` pattern.

**Frontend**
- `game-poker.js` `toggleRevealAll()`: still sets the client `revealAll` flag (board.js needs it to
  render non-`revealedTiles` as revealed), and now also `socket.emit("set_reveal_all", {...})`.
- `game-socket.js` `server_info` handler: when `debugTools===false`, also hides the
  `#chk-reveal` toggle's `<label>` (same place it already hides the Debug Tools window) — so the cheat
  isn't offered in production. Defense-in-depth alongside the server-side `DEBUG_TOOLS` gate.

Render path (both pieces needed): server sends real tile data (type ≠ "hidden") AND the client
`revealAll` flag makes board.js treat not-yet-revealed tiles as revealed. The reveal appears on the
server's fresh `game_update` (instant on localhost).
