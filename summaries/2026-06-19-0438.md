## Arming (pre-select)
- **backend/gameLogic.js**: new per-player private field `armedRoll = {value,revealed}|null`. Init `null` in `addPlayer`; reset in `_resetToLobby` + `completeReveal`; cleared in `useRollCard` (after splice), `rollDice` (after guards), and `endTurn` (just-ended player) — so an arm is strictly "for your upcoming turn" and never lingers. New methods `armRollCard(socketId,value,revealed)` (validates playing state, live player, value 1..6, and that the player actually HOLDS that value in the chosen collection) and `disarmRollCard(socketId)`. getState `_redactedPlayers` adds `armedRoll: isViewer ? (p.armedRoll||null) : undefined` — **owner-only** (the `{...p}` spread would otherwise leak the value; verified the bot never sees P1's armedRoll).
- **backend/server.js**: `arm_roll_card {value,revealed}` / `disarm_roll_card` handlers.
- **frontend/game-items.js**: `armRollCard(value,revealed)` / `disarmRollCard()` emitters.
- **frontend/game-screen.js** (showGame render block): `armed = me.armedRoll`; `canArm = inPlaying && hasCards && live && !startPickPending && !isMyTurn` (OFF your turn only). Click routing per chip: `canPlayCard` → play; else `canArm` → toggle (`isArmed ? disarmRollCard() : armRollCard(v, revealedFlag)`); else disabled. `isArmed` matches value AND collection. The armed ring is added ONLY on interactive chips (never disabled). Subtitle varies by play/arm/turn state.
- **frontend/styles.css**: `.roll-chip-armed` (outline ring + glow + corner ::before dot) + a disabled guard so a disabled chip never shows the ring.
