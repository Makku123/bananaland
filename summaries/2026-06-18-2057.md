# Run summary — 2026-06-18 20:57 PT

Two Pineapple Bomb changes (both modes), plus a pre-existing auction soft-lock
fix surfaced along the way.

## 1. Buying is decoupled from planting
Previously the first `placeBomb` both **bought the tree and planted a bomb**.
Now they're separate:
- **`buyBombTree(socketId)`** — new one-time purchase, own-turn-only. Costs
  `bombCost` (half the Super Banana, burned to the ledger), gated on affording
  the **full** Super Banana price, sets `bombTree=true` + `bombRadius=1`. Does
  **not** plant anything.
- **`placeBomb`** — now **requires owning the tree** (returns false otherwise),
  stays free, own-turn-only, one-on-board. Plant whenever you like on later turns.

## 2. Upgradeable blast radius
- **`upgradeBombTree(socketId)`** — own-turn-only; costs `bombCost` each time;
  `bombRadius += 1`; **no cap** (repeatable). Allowed even while a bomb is live
  (only planting a 2nd bomb is blocked).
- **Radius snapshots at plant time** (per user's choice): an already-ticking bomb
  keeps the radius it was planted with; upgrades only grow **future** bombs.
- **Blast** (`_detonateBomb`) now uses `bomb.radius`: tiles **P−R … P+R** with
  loop wrap, deduped via a Set (R≥24 covers the whole board, each tile once).
  Opponents-only / placer+teammates immune / farms untouched / timer-only — all
  preserved.
- `getState` ships `radius` to the placer's team; opponents still see no bombs.
  The board draws a faint **footprint** over every tile the blast will hit (team-
  visible), and the upgrade button shows `r{N}→{N+1}`.

## Bonus fix — auction PITCH-phase ghost/leaver soft-lock (pre-existing)
Decoupling the bomb changed a fuzz trajectory (seed 77) and exposed a real,
unrelated soft-lock: a **non-lander bidder who ghosts/leaves during a farm
auction's `pitch` phase** stayed in `a.bidders`, so the pitch→respond transition
re-armed them as a bidder **owing a response that never comes** — a permanent
stall with the auction timer off. `makeGhost` and `removePlayer` only handled the
`respond`/`silentbid` phases. Added a `pitch` branch to **both** (drop the player
from `a.bidders` + `a.bids`). The item auction was already safe (it rebuilds its
bid list, filtering ghosts, at respond time). Added a direct regression test
(17u) plus restored/expanded bomb coverage in the fuzz (buy+plant+upgrade).
