## 3. SB auction lander PICKS the card value (1..6) AND pitches its price
Was: landing-can't-afford / crossing-can-afford auto-picked a RANDOM card N and ran the auction. Now the lander chooses N themselves.
- New **cardpick pre-phase**. Both triggers (`_processLanding` can't-afford, `_resolveSuperBananaCross` can-afford) now call `_startCardAuctionPick(landerId)` instead of `_createCardAuctionForLander(id, randomN)`.
- `_startCardAuctionPick`: opens a lightweight placeholder `this.auction = {cardAuction:true, cardPick:true, phase:"cardpick", landingPlayer, bids:{[lander]:…}, willPitch, cardValue:null}`. `willPitch = lander.money>0 && (#other eligible bidders)>0` — UI hint for whether a price keypad is shown (false ⇒ free award or broke-lander sealed, so price is moot). The placeholder is a live `this.auction`, so turn auto-end is suppressed + landing-poker is skipped until resolved.
- `pickCardAndPitch(socketId, value, price)`: validates lander + value 1..6, tears down the placeholder, calls the **existing** `_createCardAuctionForLander(landerId, value)` (untouched — all its free/sealed/2v2/pitch shortcuts reused), then if a pitch auction opened applies the price via the existing `placeBid` (caps/validation reused). Free-award (0/1 eligible) leaves no auction → schedules the lander's auto-end. Socket: `pick_card_auction {value, amount}` (server.js).
- `getState`: serialize `cardPick`/`willPitch`; `cardValue` stays lander-only (null during cardpick / for non-landers — no leak).
- Ghost/leave safety: lander leaving mid-cardpick → existing leave handler clears `this.auction` (bids[lander] present). Lander ghosting → new `_maybeDriveGhost` branch clears the placeholder + ends the turn (ghosts can't pick/win; card forfeited).
- Frontend: new `#auction-cardpick` block in index.html (1–6 picker + Confirm). `updateAuctionPanel` cardpick branch: lander sees picker; willPitch ⇒ reuse keypad ("Pitch Card"); else Confirm-only ("you keep it" / "broke ⇒ sealed"); non-landers see a waiting line. `placeBid()` delegates to `pickCardAuction()` in cardpick phase. New `selectCardPickValue`/`_renderCardPickButtons`/`pickCardAuction`; `_getBidMax` + default-bid prefill extended to cardpick; selection reset when phase≠cardpick. CSS `.cardpick-*` mirrors `.bid-key`.
