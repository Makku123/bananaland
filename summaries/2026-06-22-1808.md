## Sorcery-card GROW-MATCH gamble (backend + frontend)

**User request:** When a player grows via grow-match using a Sorcery Card, they must
roll 2d6 **three times** (was "twice", updated mid-task). If **any** of those rolls
matches the grow number N on the card → the grow **fizzles** (grows nothing) and they
just walk. If **none** match → the grow fires at **3× each farm's yield**. The player
**always walks 7−N**. **N=1 auto-passes** (a 2d6 can never total 1) → 3×, no rolls.
Rolls are **auto-rolled by the server and shown**. Regular (non-rune) dice
grow-matches are **unchanged**.

### Backend (`gameLogic.js`)
- `_fireGrowAt(player, growPos, source, mult = 1)` — new `mult` arg; per-farm
  `amount = prop.price * mult` (threads through minted / early-pickup / pile-add /
  grownAmounts). `mult = 3` for a passed gamble.
- New pure predicate `_wouldRolledGrowFire(value)` (refactored out of
  `_processRolledGrow`) — "would N fire a revealed grow?" without firing.
- `useRollCard` normal-rune branch no longer calls `_growMatchMove`; it inlines the
  `7−N` walk + `lastGrowMatchHop`, then calls the new `_runeGrowGamble(cur, N)`. Adds
  `+2600ms` to `walkAnimMs` when a gamble fired.
- `_runeGrowGamble(player, N)` — only when `_wouldRolledGrowFire(N)`. Rolls 2d6 three
  times (`Math.random`); fizzle if any sum === N, else `_fireGrowAt(...,3)`. N=1 skips
  rolls (auto-pass). Sets transient `lastGambleResult = {n, rolls:[[d,d]...], passed,
  skipped}`.
- `lastGambleResult`: ctor-init null, nulled at all 4 reset sites (rode the shared
  `lastGrowMatchHop = null` block), shipped top-level in `getState`.

### Frontend (`game-screen.js`, `styles.css`)
- `_showSorceryGamble(res)` — body-fixed `.sorcery-gamble` overlay centered on the
  board (modeled on `_showGrowMatchHop`): title, three rolls (`.sg-hit` red /
  `.sg-miss` green by sum vs N), outcome ("GROW ×3!" / "GROW N FIZZLED" / auto-pass).
  Self-cleaning (animationend + 3200ms safety).
- Triggered from the universal dice/walk block when `gs.lastGambleResult` is present;
  `walkDelay` bumped to `max(base, 2800)` so the reveal plays before the walk (the
  walk's `_tokenWalking` already holds end-turn). Shows to all viewers.
- CSS `.sorcery-gamble` / `.sg-*` + `@keyframes sgIn / sgRollIn / sgOutcomeIn` +
  reduced-motion, appended at EOF.
