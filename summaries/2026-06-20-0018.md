# Session 2026-06-20 0018 — Armed-roll path preview + per-grow owned-farm totals

Two new frontend features (no backend changes).

## A. Armed guaranteed roll → highlight the travel path + destination on the board
`board.js` `renderBoard`: when the VIEWER has `me.armedRoll` set (owner-only), compute the path the
armed roll would take and light it up:
- path = `(me.position + 1 .. me.position + steps) % boardLen`, where `steps = me.negativeRolls ?
  13 - value : value`.
- crossed tiles get `.armed-path` (cyan dashed glow); the landing tile gets `.armed-path-dest`
  (solid cyan + a gentle brightness pulse) — matching the armed-chip's cyan ring.
- The class is applied in the tile loop **before** the fog branch, so hidden crossed tiles also glow
  (just on the fog cover — no content leak). Recomputed every render; armedRoll is owner-only so only
  the armer sees their own path.
- `styles.css` `.space.armed-path` / `.armed-path-dest` use `!important` to beat the `owned-*` tile
  borders.

## B. Per-grow-category total yield in OWNED FARMS
`game-screen.js` `buildOwnedFarmsHtml`: each grow group's header now shows the **sum of that group's
farms' yields** (`.owner-set-total`, gold, right-aligned to line up with the per-farm yields). E.g.
GROW 6 with F37+F29+F22 shows **88🍌** — i.e. what that grow pays out when it fires.
- Geometric note: the existing grouping (`anchorGrowOf` = nearest revealed grow *behind* a farm,
  counterclockwise) is identical to "the grow whose clockwise `_growRange` firing-bounds contains the
  farm", so the per-group total is exactly that grow's payout. Matches the user's example (grow with
  F30+F40 → 70).
- The "No grow tiles revealed yet" bucket also shows a total.
