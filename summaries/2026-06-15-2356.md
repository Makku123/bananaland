## The negotiation (lander A1 + teammate A2 vs opponents B1/B2)

- A1 pitches price P (min 1🍌, capped at the richest OTHER player's money).
  **Lander Buy Now**: if A1 can out-bid both OPPONENTS (teammate excluded), they
  instantly buy for richest-opponent + 1.
- Only players who can **afford P** participate.
- Affordable opponents race to **Accept** (first = contender) or all reject.
  - All reject → A2 (if affordable) Accept (A2 buys at P) / Reject (A1 buys at P);
    A2 can't afford → A1 buys.
  - An opponent accepts → A2 (if affordable): Reject (that opp buys at P) / Accept
    (contest at P) / Raise +X (P+X, capped by A2's money) / **Teammate Buy Now**
    (other opp's money + 1, only if A2 richer). Only ONE opp in → A2 gets just
    Accept/Reject (no raise).
  - After A2 Accept/Raise → the OTHER opponent decides at the current total:
    Accept (buys, must afford) / Reject (A2 buys at total).
- **Broke lander (money 0)**: no pitch; opponents race to accept; first acceptor
  and A2 (if A2 has money) settle a **2-way silent bid** (tie → A2). Both broke →
  first opponent to accept gets it free.
- **Shortcuts**: exactly 1 player with bananas → free to them; nobody has
  bananas → lander gets it free.
- Timeouts: a missed step = the passive choice (reject). The old 5s
  teammate-accept wait is removed for FARM auctions (still applies to item
  auctions).

## Bug found this run (7th, from the focused re-review)

- **Lander Buy Now mispriced in 2v2.** `_buyNowPrice` counted the lander's
  teammate as an "opponent," so the lander would over-pay (teammate + 1) to
  out-bid their own partner, and the "strictly richest" gate included the
  teammate. Fixed: in teams mode the opponent set excludes the lander's own team,
  so Buy Now = richest **opponent** + 1 and is offered whenever A1 can beat both
  opponents (a richer teammate no longer blocks it). Regression tests 15 / 15b.

  *Interpretation note for the user:* you said "second highest score + 1 like in
  free-for-all." I read "nobody richer" / "second highest" as relative to
  **opponents only** (your teammate is on your side, so out-bidding them is
  pointless). Say the word if you actually want the teammate counted.
