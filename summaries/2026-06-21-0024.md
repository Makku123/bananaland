# Session 2026-06-21 0024 — Rune counter beside each profile, bigger & more visible

User: "put the rune counter beside each of the players profiles instead of below. Also make it
bigger and more visible."

Pure FRONTEND change to the in-game players panel (`.players-box .pstat` rows). The per-player
rune counter is `_rollCardPanelHTML(p)` → `.pstat-cards > .mini-roll-card.mini-roll-card-back`
(a face-down 🎲 card stamped with the concealed rune COUNT).

## Why it was "below"
`.pstat-cards` had `flex: 0 0 100%` + a top-border divider, forcing it onto its OWN full-width row
beneath the profile + money.

## Changes
**`game-screen.js`** (both the team and non-team player-list branches):
- Moved `_rollCardPanelHTML(p)` to sit right AFTER the name span (beside the profile), before the
  pile/money.
- Gave the name span a `pstat-name` class so it can be constrained.

**`styles.css`**
- `.pstat-cards`: `display:flex`→ inline flex item (`flex: 0 0 auto`, `margin: 0 2px`); dropped the
  `flex:0 0 100%` full-width + `border-top` divider so it no longer drops to its own row.
- New `.pstat-cards .mini-roll-card-back` (scoped, so other `.mini-roll-card` uses are untouched):
  **30×38** (was 19×23), bigger count **18px** (was 11px), bolder `🎲` mark, + a purple glow
  (`0 0 9px rgba(150,110,220,.6)`) for visibility.
- `.pstat-name`: `min-width:0` + `overflow:hidden` + ellipsis + `flex:0 1 auto` so a long name
  truncates instead of bumping things to a new line.
- `.players-box .pstat`: `flex-wrap: wrap` → **`nowrap`**. KEY FIX: with wrap, the browser line-breaks
  by base size and only shrinks WITHIN a formed line, so the name never shrank and money wrapped
  below. nowrap makes the name shrink (ellipsis) so monkey | name | rune | [pile] | money all stay
  on ONE line.

## Verify (live DOM geometry; screenshots wedged this session)
Forced `#screen-game` visible, injected synthetic `.pstat` rows via the real `_rollCardPanelHTML`:
- normal name, long name, and with-a-pile: in ALL three the rune badge, name, and money share the
  same vertical band (one line), rune is beside the name, money is right-aligned, and there's NO
  horizontal overflow (long name ellipsizes; with a pile the name shrinks to ~20px).
- Badge renders 30×38 with an 18px count (bigger/more visible).
- Row height grows ~36px→54px to fit the bigger badge; the panel's scroller (`#panel-owners`,
  `overflow-y:auto`) absorbs it, so 6-player games scroll rather than overflow.
- `node --check game-screen.js` clean.

## Notes
- Players with 0 runes show no badge (`_rollCardPanelHTML` returns "") → those rows stay short.
- `nowrap` is scoped to `.players-box .pstat` (the in-game panel only); lobby/other lists unaffected.
- Trade-off accepted for the narrow (~179px) panel: names ellipsize so the bigger badge + money fit
