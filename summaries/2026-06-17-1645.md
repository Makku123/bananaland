# Run summary — 2026-06-17 16:45 PT

Three updates: free-for-all up to **6 players** (+ two new colours), a renamed
**Team Mode** containing **2v2 and 3v3**, and **team-mode item auctions** now
following the same pipeline as team farm auctions. Reviewed adversarially; 5
findings (2 high) fixed; regression-reviewed clean.

## 1. Free-for-all up to 6 players (+ purple & pink)

- Classic max raised 4 → **6**. Two new player colours **purple 🟣** and **pink
  🌸** added everywhere: `addPlayer`/`changeColor` palette, `MONKEY_EMOJI`
  (game-core.js + game-lobby.js), the lobby colour picker, `colorNames`,
  `SIMPLE_PLAYER_COLOR_HEX` (grow-pulse / bomb-flame / leaver-cover tints), and
  the CSS `.c-purple` (#9b59b6) / `.c-pink` (#ff5fa2) for token bg, lobby avatar,
  chat dot/name/mention, and bomb kill-glow. Lobby renders up to 6 slots;
  create-page + lobby max-players selects offer 2–6.

## 2. Team Mode — 2v2 & 3v3

- The old "2v2 mode" is now **Team Mode** with two options: **2v2** (4 players)
  and **3v3** (two teams of three, exactly 6 players). Turns alternate between
  teams (A,B,A,B[,A,B]).
- Backend generalized: `_isTeams()` covers both; `_teamSize()` (2/3) and
  `_teamPlayerCount()` (4/6) drive maxPlayers, the `startGame` team build +
  interleave, and `switchTeam` mirror math. Every hardcoded `=== 4` / `"2v2"`
  site (bombs, super-banana team win, getState) widened to team-aware. Frontend:
  "Team Mode" create-page cards (2v2/3v3), lobby team tags / switch / start
  gating by team size, and every `gameMode` check widened to include `3v3`.

## 3. Team auctions — farm & item share one pipeline

- **Farm auction** generalized from a single teammate to a **teammate race**: the
  lander pitches P → opponents race (first accept wins) → if all reject, the
  teammate(s) race (first accept wins; 2 racers in 3v3) → if all reject, the
  lander keeps it at P. Broke lander → closest opponent free (no teammate step).
  `teammateId` → `teammateIds[]`/`affMateIds[]` in state, getState, and the
  reconnect rebind; `updateAuctionPanel` renders the race + fellow-teammate
  statuses.
- **Item auction (team mode)** reworked to mirror the farm pipeline EXACTLY:
  wheel picks a mystery item (starter-only) → starter pitches a blind price →
  opponents race (**first-to-accept, no silent tie-break**) → teammate(s) race →
  starter keeps at the pitched price. Broke starter → free to the closest
  opponent only if no one accepts. Classic (free-for-all) item auctions are
  **unchanged** (wheel → pitch → respond → silent tie-break / sealed bid).
  `_serializeItemAuction` exposes the team fields + teammate-visible bids;
  `updateItemAuctionUI` renders the respondOpp/teammateFinal races; leaver/ghost
  disentangle wired in both `leaveGame` and `makeGhost`.

## Review findings (5 confirmed) — fixed

4-dimension adversarial review (each finding double-verified):

1. **[HIGH] Team item-auction deadlock** — a solvent starter facing all-broke
   (money 0, **not** bankrupt) others had no valid pitch and no timer, stalling
   the held turn forever. Added a free-award guard in `_beginItemTeamPitch`
   (mirrors the farm/classic "≤1 eligible bidder" shortcut) + a regression test.
2. **[HIGH] Lobby Max-Players dropdown** only had 2–4, breaking classic 5/6-player
   lobbies (blank select + silent shrink to 4). Added options 5 & 6.
3. **[LOW]** `updateLobbySettings` tested an impossible `"teams"` value → now
   `2v2`/`3v3` (sets the right max + disables).
4. **[LOW]** Removed a dead 5-second teammate-wait block in the classic
   `respondAuction` path (unreachable; team flow returns earlier).
5. **[LOW]** `SIMPLE_PLAYER_COLOR_HEX` lacked purple/pink → grow-pulse / bomb-flame
   / leaver-cover tints fell back to generic colours; added matching hexes.

A focused regression review of all five fixes returned **0 findings**.
